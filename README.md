# homebrew-tap

Homebrew casks for my own tools.

```sh
brew install macintacos/tap/herdr-scratch
```

| cask | |
| --- | --- |
| [`herdr-scratch`](https://github.com/macintacos/herdr-scratch) | A scratch shell for [herdr](https://herdr.dev), in a popup you toggle with one chord |
| [`herdr-reshape`](https://github.com/macintacos/herdr-reshape) | Move the focused [herdr](https://herdr.dev) pane, and best-fit a tab into an even grid |

Each cask prints what is left to do after installing — `brew info <cask>` shows it
again later.
